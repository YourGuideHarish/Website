🔍 VLOOKUP
=VLOOKUP(lookup_val, table_array, col_index, [range_lookup])
=VLOOKUP(A2, $D$2:$G$100, 3, 0)
range_lookup = 0Exact match (use this!)
range_lookup = 1 (or omit)Approximate match (sorted data)
col_index = 3Return value from 3rd column of table
⚠ VLOOKUP only looks RIGHT. Lookup column must be leftmost.
🔍 HLOOKUP
=HLOOKUP(lookup_val, table_array, row_index, [range_lookup])
=HLOOKUP("Q1", $A$1:$D$5, 3, 0)
Like VLOOKUPbut searches horizontally (row 1)
row_index = 3Returns value from 3rd row
⭐ INDEX + MATCH (Preferred)
=INDEX(return_range, MATCH(lookup_val, lookup_range, 0))
=INDEX(C:C, MATCH(A2, B:B, 0))
INDEX(array, row, [col])Return value at position
MATCH(val, range, 0)Find position of val in range
AdvantageLookup LEFT, no column counting, faster
2-way lookup=INDEX(A:Z, MATCH(v1,A:A,0), MATCH(v2,1:1,0))
💡 INDEX+MATCH is more flexible than VLOOKUP. Prefer it.
✨ XLOOKUP (Excel 365)
=XLOOKUP(lookup_val, lookup_array, return_array, [if_not_found], [match_mode])
=XLOOKUP(A2, B:B, C:C, "Not found", 0)
match_mode = 0Exact match
match_mode = -1Exact or next smaller
Can return multiple columnsReturn a range as return_array
ReplacesVLOOKUP + HLOOKUP + INDEX/MATCH

🔄 Pivot Tables
  1. Select data → Insert → PivotTable → Choose location
  2. Drag fields: Rows (categories), Columns (cross-tab), Values (numbers), Filters
  3. Values field: Default is SUM. Right-click → Summarize by: Count, Average, Max, Min
  4. Right-click → Show Values As: % of Row, % of Column, Running Total, Rank
  5. Group dates: Right-click a date → Group → by Month, Quarter, Year
  6. Sort: Click dropdown arrow in pivot → Sort A→Z or by Values
  7. Add Slicers: PivotTable Analyze → Insert Slicer (visual filter)
  8. Refresh: Right-click → Refresh (data changes don't auto-update)
  9. Calculated Field: Analyze → Fields, Items → Calculated Field
💡 GETPIVOTDATA pulls data from pivot: =GETPIVOTDATA("Sales", $A$3,"Region","North")

🔑 Key Analytics Concepts to Know
📌 VLOOKUP vs INDEX/MATCH

VLOOKUP is simpler but limited (right-only). INDEX/MATCH is flexible — can look left, two-way lookup, more robust when columns shift.

📌 Absolute vs Relative Refs

Critical when copying formulas. Use $A$1 to lock, A1 to let it shift. F4 cycles through all 4 modes.

📌 Pivot Table Refreshing

Data added to source doesn't auto-refresh. Right-click → Refresh, or change data source if range expanded.

📌 SUMPRODUCT for OR Logic

=SUMPRODUCT((A:A="NY")+(A:A="CA")>0, B:B) — use > 0 to prevent double-counting overlaps.

📌 Named Tables (Ctrl+T)

Convert data to a Table for auto-expand, structured references, easier pivot setup, and Power Query integration.

📌 Error Handling Pattern

=IFERROR(your_formula, "fallback") wraps any formula. For VLOOKUP specifically, =IFNA is more precise.

🧠 Must-Know Tips for Interview
🔑 Paste Special: Values

Ctrl+C → Ctrl+Alt+V → V → Enter. Paste calculated values without formulas. Essential for removing formula dependencies.

🔑 Text to Columns

Data → Text to Columns → Delimited. Split comma/space-separated data into columns. Also fixes dates stored as text.

🔑 AutoFill Patterns

Type Mon, Tue → drag handle → Excel continues. Works for dates, months, quarters, custom lists. Double-click fill handle to fill to last row.

🔑 Named Tables vs Ranges

Ctrl+T creates a Table. Formulas use =Table1[ColumnName]. Auto-expands when new rows added. Works beautifully with XLOOKUP and pivots.
